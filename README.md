# IdeaForge — AI-Powered Idea Management

## 🚀 Quick Start on StackBlitz

1. Open the StackBlitz project link
2. In the left panel, create a new file called `.env`
3. Add this line: `VITE_ANTHROPIC_API_KEY=your_key_here`
4. Get a free API key at https://console.anthropic.com
5. The app will reload automatically — AI features are now live

## Features

- 💡 **Idea Feed** — Browse, like, comment, share, and save ideas
- ✦ **AI Intake** — Submit ideas via structured AI conversation
- 📥 **Bulk Import** — Upload CSV of existing ideas with outreach
- 🔔 **Staleness Center** — 30-day follow-up and archival system
- 📊 **Dashboard** — Portfolio analytics and engagement tracking

## Running Locally

```bash
npm install
echo "VITE_ANTHROPIC_API_KEY=your_key" > .env
npm run dev
```
